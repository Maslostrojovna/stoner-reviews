# Stoner Reviews code-checkout entry point

In the shared desktop workspace, read the authoritative Stoner Reviews/AGENTS.md,
PROJECT.md, HANDOFF.md, BRAND.md and IMAGE-WORKFLOW.md outside Code/ before work.
Run Code/link-knowledge.py after creating a worktree to link shared guidance locally.
Create local worktrees only under Code/. Do not commit workstation-specific links.

For a standalone clone, read the deployment and database READMEs and latest release
report. Preserve approved editorial copy, independent scores, V7/reflection branding,
palette, full-composition artwork, server-rendered review content and permanent URLs.
Never infer missing ratings or calculate Overall from other dimensions.

Inspect dirty/branch/remote state. Preserve user edits; do not reset/clean/stage all.
Do not upload source packs, private material, credentials or the repository root.
Build uses the explicit public asset allowlist. Production D1 writes, push/deploy
and rollback require explicit authorization. Local D1 uses --local and its own state.
